# Muhammed CRM - نظام إدارة العملاء العقاري

## 🎯 نظرة عامة
نظام CRM متكامل لإدارة العملاء العقاري مع نظام صلاحيات متعدد المستويات وتوزيع الأرقام على فريق المبيعات.

## ✨ الميزات الرئيسية

### 🔐 نظام تسجيل الدخول
- **صفحتان منفصلتان**: دخول الإدارة ودخول السيلز
- **حساب المدير الافتراضي**: 
  - اسم المستخدم: `admin`
  - كلمة المرور: `admin123`

### 👥 نظام الأدوار

#### الإدارة (Admin/Supervisor)
تبويبات الإدارة:
1. **فريق العمل** - عرض السيلز والمشرفين مع إمكانية عرض الفيدباك اليومي لكل شخص
2. **الفيدباك اليومي** - عرض إحصائيات وفيدباك كل سيلز
3. **توزيع الأرقام** - إضافة أرقام جديدة وتوزيعها على السيلز
4. **إنشاء حسابات سيلز** - إنشاء حسابات جديدة للسيلز
5. **الإعدادات** - تصدير البيانات وإعدادات النظام

#### السيلز (Sales)
تبويبات السيلز:
1. **الرئيسية** - لوحة التحكم مع الإحصائيات
2. **العملاء** - إدارة العملاء مع إمكانية إضافة أرقام متعددة
3. **المراحل** - عرض العملاء حسب المرحلة (Pipeline)
4. **العقارات** - إدارة العقارات مع بحث ذكي
5. **التذكيرات** - إدارة تذكيرات الاتصال
6. **الفيدباك** - تسجيل الفيدباك اليومي
7. **أرقام جديدة** - عرض الأرقام الموزعة من الإدارة
8. **التقارير** - إحصائيات وتقارير الأداء

### 📞 نظام توزيع الأرقام

#### للإدارة:
- إضافة أرقام جديدة من تبويب "توزيع الأرقام"
- تحديد السيلز الذي سينزل له الرقم
- إضافة وصف/ملاحظات للرقم
- عرض حالة كل رقم (جديد / تم العرض / تم التواصل / مغلق)

#### للسيلز:
- عرض الأرقام المخصصة له فقط في تبويب "أرقام جديدة"
- حالة الرقم:
  - **رقم جديد**: لم يشاهده السيلز بعد
  - **تم العرض**: شاهد السيلز الرقم
  - **تم التواصل**: تم الاتصال بالعميل
  - **مغلق**: تم إغلاق الصفقة
- زر "تم العرض" لتأكيد مشاهدة الرقم
- زر "اتصال" للاتصال المباشر

### 🔍 البحث الذكي في العقارات

يدعم البحث عن العقارات بـ:
- **الأرقام**: `1000000` أو `1,000,000`
- **الكلمات العربية**: `مليون`, `مليونين`, `ألف`, `نصف مليون`
- **النص**: اسم العقار، النوع، الموقع

**مثال**: 
- البحث عن `مليون` سيعرض العقارات المكتوب سعرها `1,000,000` أو `مليون`
- البحث عن `1000000` سيعرض العقارات المكتوب سعرها `مليون` أو `1,000,000`

### 💰 نظام الأسعار
- **فواصل تلقائية**: الأسعار تظهر بفواصل (مثل: `1,500,000`)
- **دعم الكلمات العربية**: يمكن كتابة السعر بالكلمات (مليون، ألف، إلخ)
- **تحويل تلقائي**: يتم تحويل الكلمات إلى أرقام للحفظ والبحث

### 📊 الفيدباك اليومي

#### للإدارة:
- عرض كل سيلز في بطاقة مع إحصائيات:
  - عدد فيدباك اليوم
  - عدد مكالمات اليوم
  - إجمالي الفيدباك
  - إجمالي المكالمات
- الضغط على أي سيلز يعرض كل الفيدباك اليومي الخاص به

#### للسيلز:
- تسجيل فيدباك يومي لكل عميل
- حالة الاتصال:
  - تم الاتصال
  - لا رد
  - مشغول
  - لم يتصل
- مدة المكالمة
- الإجراء التالي
- ملاحظات

### 👤 إدارة العملاء
- إضافة عميل جديد مع:
  - الاسم ورقم الهاتف الرئيسي
  - **أرقام إضافية** (يمكن إضافة أكثر من رقم)
  - العقار المطلوب
  - الميزانية
  - القسط الشهري
  - مدة الاستلام
  - المصدر (كامبين / فيسبوك / خارجي)
  - المرحلة (جديد → تم التواصل → موعد معاينة → تفاوض → تم البيع / ضائع)
  - ملاحظات

### 🔔 نظام التذكيرات
- إضافة تذكير للاتصال بعميل في وقت محدد
- **إشعارات متعددة**:
  - صوت تنبيه
  - اهتزاز الجهاز
  - إشعار متصفح (يعمل حتى لو الصفحة مغلقة)
  - إشعار داخل التطبيق
- تأجيل التذكير (30 دقيقة / ساعة)
- عداد التأجيلات

### 📈 التقارير والإحصائيات
- نسبة التحويل
- عدد المكالمات
- توزيع المصادر (كامبين / فيسبوك / خارجي)
- ملخص المراحل

## 🚀 التشغيل

### المتطلبات
- Node.js 18+
- npm أو yarn

### التثبيت
```bash
npm install
```

### التشغيل
```bash
npm run dev
```

ثم افتح: `http://localhost:5173`

### البناء للإنتاج
```bash
npm run build
```

## 💾 تخزين البيانات

جميع البيانات محفوظة في `localStorage` في المتصفح:
- `crm_users` - بيانات المستخدمين
- `crm_clients` - بيانات العملاء
- `crm_properties` - بيانات العقارات
- `crm_reminders` - التذكيرات
- `crm_daily_feedback` - الفيدباك اليومي
- `crm_assigned_leads` - الأرقام الموزعة

## 🎨 التصميم

- **الألوان**: بنفسجي متحرك مع خلفية سوداء
- **الأنيميشن**: Framer Motion لحركات سلسة
- **التصميم**: Glass Morphism احترافي
- **الاستجابة**: متوافق مع جميع الأجهزة

## 🔒 الأمان

- فصل كامل بين بيانات الإدارة والسيلز
- كل سيلز يرى بياناته فقط
- الإدارة ترى كل البيانات
- التحقق من الصلاحيات في كل عملية

## 📝 ملاحظات مهمة

1. **حفظ البيانات**: البيانات محفوظة في المتصفح فقط، استخدم زر "تصدير البيانات" للنسخ الاحتياطي
2. **الإشعارات**: يجب السماح بالإشعارات في المتصفح لتعمل بشكل صحيح
3. **البحث**: البحث في العقارات يدعم الأرقام والكلمات العربية
4. **الأرقام المتعددة**: يمكن إضافة أكثر من رقم لكل عميل
